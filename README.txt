BILLY JOE LAGUER - PERSONAL PORTFOLIO
=====================================

PROJECT FILES
-------------
index.html                 Main portfolio page
style.css                  Custom styles and responsive layout
script.js                  Navigation and contact form interactions
assets/                    Your supplied portfolio photos

HOW TO RUN
----------
1. Extract the ZIP file.
2. Keep the assets folder in the same location as index.html.
3. Open index.html in Google Chrome, Microsoft Edge, Firefox, or another browser.
4. An internet connection is needed to load Bootstrap, Bootstrap Icons, and Google Fonts
   from their CDNs. The page layout and your local photos are stored in this project.

PAGE SECTIONS
-------------
- Home: Portfolio introduction and outdoor profile photo.
- About Me: Your biography and portrait.
- Achievements: Best Outside Spiker, Best Point Guard, and team championship.
- Contact Me: Name, address, and message fields, plus your phone, email, and Facebook.

EDITING YOUR INFORMATION
------------------------
- Open index.html in a code editor such as Visual Studio Code.
- Edit the text, phone number, email address, or Facebook link in index.html.
- Replace photos in the assets folder using the same filenames if you want to update them.
- Change colors, spacing, fonts, and layout in style.css.
- Update interactive behavior in script.js.

CONTACT FORM NOTE
-----------------
The contact form uses a mailto link. When a visitor submits it, their default email
application opens with the message prepared for Billyjoelaguer@gmail.com. The visitor
must still press Send in that email application. To receive messages directly on the
website without opening an email app, connect the form to a server or a form service.

BUILT WITH
----------
HTML5, CSS3, JavaScript, Bootstrap 5.3.3, Bootstrap Icons.
